# 直连模式 · Direct

适用于能直接连接 Tailscale 的网络。Claude、Firefox 和终端通过网关容器连接你选择的出口节点。使用已加入自己 tailnet 且获准充当出口的设备。

在 Windows 双击仓库根目录的 [Setup.cmd](../Setup.cmd)，然后按[中文快速入门](../README.zh-CN.md)或[英文快速入门](../README.md)选择出口和项目文件夹。

Existing installations retain their Compose project and volume identifiers. When updating an older checkout in place, see the [upgrade notes](../docs/setup.md).
